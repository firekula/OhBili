# Feature Specification: 我的页内容库（历史记录 / 我的收藏 / 稍后再看 / 离线缓存）

**Created**: 2026-11-18
**Status**: Draft
**Input**: User description: "继续完成我的页面里面的离线缓存、历史记录、我的收藏和稍后再看。"

## Overview

为 OhBili phone 端"我的"页四宫格入口（离线缓存/历史记录/我的收藏/稍后再看）补齐真实功能：前三个为 B 站账号云端数据的浏览与管理（支持删除/移除/清空等操作，并在视频页提供收藏、稍后再看入口）；离线缓存提供完整方案（清晰度选择下载、下载进度、缓存管理、断网本地播放）。实现顺序为先易后难：历史记录 → 我的收藏 → 稍后再看 → 离线缓存。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 浏览与管理历史记录 (Priority: P1)

已登录用户进入"历史记录"页，查看与 B 站账号云端同步的观看历史列表（封面/标题/UP 主/观看时间/进度），点击任意条目从上次进度继续播放；可单条删除，也可一键清空全部历史。

**Why this priority**: 四个功能中实现最轻（单接口分页列表+删除），且"找回来刚看过的视频"是最高频需求；用户指定先易后难。

**Independent Test**: 登录 → 我的页点"历史记录"→ 出现云端历史列表 → 点击一条进入播放页并从上次进度续播 → 返回列表删除该条 → 条目消失 → 清空全部 → 列表变空态。

**Acceptance Scenarios**:

1. **Given** 已登录且有观看历史, **When** 点击我的页"历史记录"宫格, **Then** 进入历史页展示云端历史列表（含封面/标题/UP 主/观看时间/进度信息），支持翻页加载更多
2. **Given** 历史列表可见, **When** 点击任一条目, **Then** 跳转播放页并从上次观看进度继续播放
3. **Given** 历史列表可见, **When** 删除单条历史（经确认弹窗）, **Then** 该条从列表移除且云端同步删除
4. **Given** 历史列表可见, **When** 点击清空（经确认弹窗）, **Then** 列表清空为空态，云端历史同步清空

---

### User Story 2 - 浏览与管理我的收藏 (Priority: P1)

已登录用户进入"我的收藏"页，查看收藏夹列表（名称/数量），进入任一收藏夹浏览收藏视频，点击播放；可在收藏夹内取消收藏单条视频；视频播放页提供"收藏"入口，可选择收藏夹进行收藏或取消收藏。

**Why this priority**: 收藏是用户主动沉淀的内容库，查找/回看价值高；实现复杂度中等（夹列表+夹内容两级页面）。

**Independent Test**: 登录 → 我的页点"我的收藏"→ 出现收藏夹列表 → 进入默认收藏夹看到收藏视频 → 点击播放 → 返回取消收藏一条 → 条目消失 → 视频页点收藏入口 → 选择收藏夹收藏成功。

**Acceptance Scenarios**:

1. **Given** 已登录且有收藏, **When** 点击我的页"我的收藏"宫格, **Then** 进入收藏夹列表页（夹名称/视频数量），展示默认收藏夹与自建收藏夹
2. **Given** 收藏夹列表可见, **When** 点击任一收藏夹, **Then** 进入夹内容页展示收藏视频列表（封面/标题/UP 主/收藏时间），支持翻页加载更多
3. **Given** 夹内容列表可见, **When** 取消收藏单条（经确认弹窗）, **Then** 该条从夹内移除，夹计数同步更新
4. **Given** 视频播放页, **When** 点击"收藏"入口, **Then** 弹出收藏夹选择（可多选夹），确认后收藏成功；对已收藏视频可取消收藏，状态即时反映

---

### User Story 3 - 浏览与管理稍后再看 (Priority: P2)

已登录用户进入"稍后再看"页，查看稍后再看列表，点击播放；可单条移除；视频播放页提供"稍后再看"入口，可添加/移除当前视频。

**Why this priority**: 与收藏同构（单级列表+增删），实现轻；但使用频率低于历史/收藏，排第三。

**Independent Test**: 登录 → 我的页点"稍后再看"→ 出现列表 → 点击播放 → 返回移除一条 → 条目消失 → 视频页点"稍后再看"添加当前视频 → 列表出现该视频。

**Acceptance Scenarios**:

1. **Given** 已登录且稍后再看非空, **When** 点击我的页"稍后再看"宫格, **Then** 进入稍后再看页展示列表（封面/标题/UP 主/添加时间）
2. **Given** 列表可见, **When** 点击任一条目, **Then** 跳转播放页播放
3. **Given** 列表可见, **When** 移除单条（经确认弹窗）, **Then** 该条从列表移除且云端同步
4. **Given** 视频播放页, **When** 点击"稍后再看"入口, **Then** 当前视频加入稍后再看（已加入则可移除），状态即时反映

---

### User Story 4 - 完整离线缓存 (Priority: P2)

已登录用户在视频播放页点"缓存"，从当前账号可用清晰度中选择档位，应用将视频与音频下载到本地（进度实时可见）；"离线缓存"页管理已缓存内容（列表/进度/存储占用/单条删除/清空）；已完成的缓存可在断网或未登录状态下完整本地播放。

**Why this priority**: 工作量最大（下载管理+本地存储+本地播放打通），用户明确放在最后做；完成后四宫格全部闭环。

**Independent Test**: 登录 → 视频页点"缓存"→ 选清晰度 → 下载开始且进度推进 → 缓存页可见该任务与存储占用 → 下载完成后关闭网络 → 缓存页点击该视频 → 本地完整播放 → 删除该缓存 → 存储占用减少。

**Acceptance Scenarios**:

1. **Given** 视频播放页, **When** 点击"缓存"入口, **Then** 弹出清晰度选择（仅列出当前账号可用的档位及预估大小），选定后开始下载
2. **Given** 下载进行中, **When** 查看离线缓存页, **Then** 可见任务条目、实时进度与总存储占用
3. **Given** 下载完成, **When** 断网（或退出登录）后进入离线缓存页点击该视频, **Then** 使用本地文件完整播放（不请求网络视频流）
4. **Given** 离线缓存页, **When** 删除单条缓存（经确认弹窗）, **Then** 本地文件释放、存储占用同步减少、列表移除
5. **Given** 下载中断（断网/应用退出）, **When** 再次进入缓存页, **Then** 该任务标记为失败/未完成状态，可重试或删除，不产生不可清理的残留

---

### Edge Cases

- 未登录点击四宫格任一入口：跳转登录引导，不发起账号数据请求；已缓存内容的本地播放不受登录态限制
- 历史为空 / 无收藏夹 / 收藏夹为空 / 稍后再看为空：各页展示对应空态文案与引导
- 收藏夹内容含已失效（审核下架/UP 删除）视频：条目置灰或标注"已失效"，点击不跳转播放
- 删除/清空/取消收藏/移除时网络失败：提示失败，列表状态不变，可重试
- 清晰度档位受大会员/登录态限制：仅展示可用档位；全不可用时明确提示
- 稍后再看达到 B 站上限：添加失败并如实展示服务端提示
- 存储空间不足：下载前/中检测并提示，不产生半写损坏文件
- 云端历史中非普通视频类型（番剧/影视/直播回放等）：降级展示为不可点击或文字提示条目，不崩溃不空白

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 我的页四宫格（离线缓存/历史记录/我的收藏/稍后再看）必须可点击并路由到对应功能页
- **FR-002**: 历史记录页 MUST 展示账号云端历史（封面/标题/UP 主/观看时间/进度），支持点击续播（跳转到上次观看进度）、分页加载、单条删除与一键清空
- **FR-003**: 我的收藏 MUST 提供收藏夹列表（名称/数量）与夹内容两级浏览（分页），支持夹内取消收藏单条
- **FR-004**: 视频播放页 MUST 提供"收藏"入口：弹出收藏夹选择（支持多夹），可收藏/取消收藏，状态即时反映
- **FR-005**: 稍后再看页 MUST 展示列表并支持点击播放、单条移除；视频播放页 MUST 提供"稍后再看"添加/移除入口
- **FR-006**: 离线缓存 MUST 提供：视频页缓存入口（清晰度选择，仅当前账号可用档位+预估大小）、下载进度实时展示、缓存管理页（任务列表/存储占用统计/单条删除/清空）、断网与未登录状态下的完整本地播放
- **FR-007**: 下载中断（断网/退出应用）MUST 标记失败/未完成状态，支持重试与删除，不残留不可清理数据
- **FR-008**: 所有破坏性操作（删除历史/清空历史/取消收藏/移除稍后再看/删除缓存/清空缓存）MUST 有二次确认
- **FR-009**: 未登录访问任一入口 MUST 跳转登录引导；已缓存内容本地播放不受登录态限制
- **FR-010**: 历史/收藏夹内容/稍后再看列表 MUST 支持分页或加载更多；各页 MUST 有空态、加载态、错误态（可重试）
- **FR-011**: 本次功能仅作用于 phone 端；tablet 端零源码改动（仅保证可构建）
- **FR-012**: 云端数据操作（删除/清空/取消收藏/收藏/移除/添加稍后再看）MUST 与 B 站服务端同步生效，失败时如实提示且本地状态不回退为成功假象

### Key Entities *(include if feature involves data)*

- **历史条目 (HistoryItem)**: 视频标识、封面、标题、UP 主、观看时间、观看进度（上次看到的时间点）、条目类型（普通视频/番剧等）
- **收藏夹 (FavFolder)**: 夹标识、名称、视频数量、是否默认夹
- **收藏视频 (FavVideo)**: 视频标识、封面、标题、UP 主、收藏时间、时效性（正常/已失效）、所属夹标识
- **稍后再看条目 (WatchLaterItem)**: 视频标识、封面、标题、UP 主、添加时间、时效性
- **离线缓存任务 (CacheTask)**: 视频标识（含分 P）、标题、封面、清晰度档位、下载状态（等待/下载中/已完成/失败）、进度、已占用存储大小、本地存储位置标识

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 我的页四宫格入口 100% 可达对应功能页（未登录时达登录引导页）
- **SC-002**: 登录用户从我的页出发，≤3 步完成"找到一条历史并从上次进度继续播放"
- **SC-003**: 正常网络下，单条删除/清空/取消收藏/移除/收藏/添加稍后再看操作成功率 ≥95%，且全部具备二次确认
- **SC-004**: 选定清晰度后 5 秒内开始下载且进度实时可见；下载完成后断网可完整播放全片
- **SC-005**: 删除缓存后存储占用统计同步减少；无不可清理的残留文件
- **SC-006**: tablet 回归构建通过（零源码改动）

## Assumptions

- 四个功能的数据均来自 B 站账号云端 API（历史/收藏/稍后再看），操作直接作用于云端账号数据，不可撤销（由二次确认兜底）
- 离线缓存下载需要登录态获取播放地址；本地播放已下载内容不需要登录态
- 离线缓存为完整下载方案：视频+音频下载到应用沙箱存储，不做边下边播、不做弹幕/评论离线缓存
- 下载清晰度仅列出当前账号可用档位（大会员档位对非会员不可见/不可选）
- 下载采用串行单任务队列，支持取消（删除）与失败重试；暂不做暂停/恢复与后台下载保活
- 历史续播依赖服务端记录的进度；本地播放不产生新的云端历史
- 延续既有工程约定：仅 phone、tablet 零改动、复用既有网络层/组件/页面模式、状态管理 V1
- 破坏性操作的网络失败按"操作失败+可重试"处理，不做乐观删除
